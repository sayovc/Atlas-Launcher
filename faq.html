Frequently asked questions

Can't find your answer? Ask on GitHub.

Is Atlas free?

Yes. Atlas is free and open source under the MIT license.

Do I need to own Minecraft?

Yes. Atlas is a launcher, not a copy of the game. To play you need Minecraft: Java Edition on a Microsoft account that owns it. Atlas includes no Mojang game files; it downloads them from Mojang's official servers or reuses files you already have.

Is Atlas official?

No. Atlas is an independent project. It isn't made, approved or supported by Mojang or Microsoft, and it isn't affiliated with any other launcher.

Can Atlas launch the game yet?

Not yet. Atlas is in pre-alpha. The app shell, settings, logs and command line work today; installing versions comes in Phase 2, and signing in and launching come in Phase 3. The app shows a feature as available only once it really works.

Does Atlas see my Microsoft password?

No. Once sign-in is available, you will sign in on Microsoft's own page in your web browser. Atlas only receives a token, which is kept in your operating system's secure credential store (Windows Credential Manager, macOS Keychain, or Secret Service on Linux), never in a plain file.

Will Atlas touch my existing Minecraft folder?

Atlas keeps all of its data in its own folder. It may read your existing Minecraft folder to reuse files it can verify, but it never writes to or deletes from another launcher's folders.

Do Fabric, Forge or NeoForge mods work?

Mod management is planned for Phase 4. Atlas will always be clear about which mods a given installation can actually run.

Does Atlas collect data about me?

No. Atlas has no telemetry, analytics or ads. See the privacy policy.

Where does Atlas store its files?

In your platform's standard app-data folder: %APPDATA%\\AtlasLauncher on Windows, ~/Library/Application Support/AtlasLauncher on macOS, and ~/.local/share/atlaslauncher on Linux. You can move it from Settings → Advanced.

How can I help?

Report bugs or suggest features on GitHub Issues, or contribute code by pull request.
