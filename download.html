Pre-alpha. Expect missing features and rough edges.

Atlas can't install or launch the game yet; that arrives in Phase 3. Today's builds are for previewing the app and testing.

Build from source

Requires Rust 1.85 or newer.

git clone https://github.com/sayovc/Atlas-Launcher
cd Atlas-Launcher
cargo run --release -p atlas-ui --bin atlas-launcher

On Linux you may need the usual desktop libraries, for example libxkbcommon-x11-0 on Debian/Ubuntu.

System requirements

  • Windows 10 or later, macOS 12 or later, or a modern 64-bit Linux desktop
  • OpenGL 3.3-capable graphics
  • Your own copy of Minecraft: Java Edition (needed to play once launching is available)

Verify your download

Each release lists a SHA-256 checksum for every file. Compare it before running anything. Later releases will also be cryptographically signed.
